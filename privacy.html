プライバシーポリシー

media-downloader（以下「本アプリ」）は、開発者本人だけが使う個人用ツールです。

  • 本アプリは Google Sheets API と Google Drive API を使い、所有者本人のスプレッドシートの読み書きと、所有者本人の Google ドライブへのファイル保存だけを行います。
  • 取得したデータは所有者本人の Google アカウント内にだけ保存します。第三者への提供、販売、共有は行いません。
  • 本アプリによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

Privacy Policy

media-downloader is a personal-use tool used only by its developer. It reads and writes the owner's own Google Sheet and saves files to the owner's own Google Drive via the Google Sheets and Drive APIs. Data stays in the owner's Google account and is never shared with, sold to, or transferred to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
